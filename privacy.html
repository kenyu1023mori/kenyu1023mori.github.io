Privacy Policy

This is a private tool used only by its owner. With the owner's own authorization, it uses the YouTube Data API and the YouTube Analytics API to upload videos to the owner's own YouTube channel and to read that channel's aggregated statistics. It does not access anyone else's account and receives no data that identifies individual viewers.

The data is used only by the owner to plan their own videos. It is not sold, not used for advertising, not shared with third parties other than the AI assistants the owner uses for analysis, and never provided for training generalized AI models. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at Google Account permissions.
